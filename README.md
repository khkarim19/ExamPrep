# Подготовка к экзамену

Личный сайт для подготовки к экзаменам, тестам и собеседованиям. Работает на вашем компьютере, ничего
не отправляет в интернет и не требует регистрации. Все ваши ответы, заметки и прогресс хранятся только у вас.

## Что умеет сайт

**Проекты.** Под каждую тему, которую вы учите (экзамен, предмет, курс), заводится отдельный проект
со своими заданиями и своим прогрессом. Все проекты видны на главной странице.

**Задания.** Внутри проекта слева список заданий. Рядом с каждым кружок: он заполняется по мере того,
как вы проходите три вкладки задания, а когда пройдены все три, превращается в галочку.

| Вкладка | Что делать |
|---|---|
| **Теория** | Читайте главы. Над ними схема связей между главами: нажмите на блок, чтобы открыть текст. Отметьте «Прочитал» у каждой главы, и вкладка засчитается сама. |
| **Словарь** | Записывайте выражения и их значения. Для заучивания есть режим «Карточки»: значение скрыто, пока вы не нажмёте. |
| **Задачи** | Разобранные примеры. Условие слева, под кнопкой «Показать решение» объяснение. Справа поле «Ваше решение»: напишите свой вариант и нажмите «Зафиксировать». |
| **Тренировка** | Решайте самостоятельно: введите ответ, сайт проверит. Завершить вкладку можно, когда все ответы верные. |

**Словарь под рукой.** Кнопка «Словарь» в верхней панели открывает записи справа на любой вкладке: можно найти выражение или добавить новое, не уходя из задания.

**Удобства.** Тёмная и светлая тема (переключатель вверху справа). Левое меню можно свернуть кнопкой
внизу. Формулы отображаются как в учебнике.

## Как запустить

Понадобится бесплатная программа [Docker Desktop](https://www.docker.com/products/docker-desktop/):
установите её и запустите. Дальше всё делается за несколько шагов.

1. **Скачайте проект.** На странице репозитория нажмите зелёную кнопку **Code → Download ZIP** и распакуйте архив.
2. **Придумайте пароль для админки.** В папке проекта создайте текстовый файл с именем `.env`
   (точка в начале обязательна) и напишите в нём одну строку:
   ```
   ADMIN_PASSWORD=ваш-пароль
   ```
   Пример лежит в файле `.env.example`. Без пароля админка закрыта, а сам сайт работает.
3. **Запустите.** Откройте терминал в папке проекта и выполните:
   ```sh
   docker compose up -d --build
   ```
   Первый запуск занимает несколько минут: скачиваются и собираются нужные компоненты.
4. **Откройте сайт:** http://localhost:3000

Чтобы остановить сайт: `docker compose down`. Ваши данные при этом сохраняются. Чтобы стереть и данные
(осторожно, это необратимо): `docker compose down -v`.

**Посмотреть, как всё выглядит.** Чтобы получить готовый демонстрационный проект с 19 темами, выполните,
когда сайт запущен:

```sh
docker compose exec backend python seed_demo.py
```

### Установить с помощью ИИ-агента

Если команды в терминале вам непривычны, поручите установку ИИ-агенту, который умеет работать с файлами
и запускать команды (например, Claude Code, Codex или Cursor). Сначала установите и запустите Docker Desktop,
затем откройте в агенте папку со скачанным проектом и отправьте ему такое сообщение:

```
Установи и запусти этот сайт по инструкции из README.md. Docker Desktop уже запущен.
Создай файл .env с ADMIN_PASSWORD, придумай надёжный пароль и скажи мне, где он лежит.
Когда сайт заработает, проверь, что http://localhost:3000 открывается, и сообщи мне.
```

Агент создаст файл с паролем, запустит сайт и расскажет, если что-то пошло не так. Пароль в чат лучше
не пересылать: он нужен только вам, и его можно посмотреть в файле `.env`.

## Как добавить свои материалы

Откройте http://localhost:3000/admin и введите пароль из файла `.env` (имя пользователя любое).

- **Проекты:** создавайте, переименовывайте, меняйте порядок, удаляйте. При удалении проекта
  пропадают все его задания, теория и прогресс.
- **Задания проекта:** добавляйте задания и открывайте их для редактирования.
- **Содержимое задания:** главы теории, задачи с разбором и вопросы для тренировки. Тексты пишутся
  в простой разметке Markdown: `**жирный**`, списки, заголовки. Формулы: `$x^2$` в строке и `$$ ... $$`
  отдельным блоком. Для главы можно выбрать, с какой другой главой она связана на схеме.
  Картинку загрузите в админке и вставьте в текст показанную ссылку.

Словарь и поле «Ваше решение» заполняются прямо на сайте, админка для них не нужна.

## Заполнить проект с помощью ИИ

Писать теорию, задачи и вопросы вручную долго. Эту работу можно отдать ИИ. Есть два способа.

### Способ 1. ИИ-агент пишет файлы тем (лучший результат)

Подойдёт агент, который умеет создавать файлы и запускать команды (Claude Code, Codex, Cursor).
Он пишет по файлу на каждую тему, а сайт сам проверяет, что структура верная.

1. Скопируйте папку `backend/content_example` в `backend/content`. В ней образец темы
   (`demo_1_fractions.py`) и реестр проектов (`projects.py`).
2. Откройте проект в агенте и отправьте ему задание. Замените части в скобках на свои:

   ```
   Заполни учебный проект «[название]» для подготовки к [экзамену / собеседованию / тесту].
   Уровень: [базовый / средний / продвинутый]. Темы: [список тем через запятую].

   Правила:
   - Образец формата — backend/content_example/demo_1_fractions.py. Сделай по одному файлу на тему
     в backend/content, назови их по образцу: [префикс]_1_..., [префикс]_2_... и так далее.
   - В теме 4–8 глав теории, 2–4 разобранные задачи и 5–10 вопросов для тренировки.
   - В вопросах тренировки ответ короткий: одно число, слово или буква варианта, строчными буквами,
     без пробелов и запятых. Для вопросов с вариантами пиши «Ответ — номер варианта» и ответ цифрой.
   - Добавь проект в backend/content/projects.py: ключ, название, префикс файлов, нужны ли формулы.
   - Проверь результат командой: python seed_content.py [ключ] --check (из папки backend)
     и исправь все ошибки, которые она покажет.
   - Не выдумывай факты, цифры и ссылки. Если не уверен, так и напиши в тексте.
   ```

3. Когда проверка проходит («content ok»), загрузите проект на сайт:

   ```sh
   docker compose up -d --build backend
   docker compose exec backend python seed_content.py [ключ]
   ```

   Проект появится на главной странице. Если загрузить тот же проект повторно, его задания заменятся,
   а прогресс, заметки и словарь по нему сбросятся. Поэтому сначала проверьте текст, потом учитесь.

### Способ 2. Чат-бот и админка (без файлов)

Если у вас обычный чат с ИИ без доступа к файлам, попросите его написать текст главы в формате Markdown
(можно с формулами в `$...$`), затем вставьте результат в админку: `/admin` → проект → задание →
«Добавить главу». Так же добавляются задачи и вопросы тренировки. Это дольше, зато не нужны файлы
и команды.

### Как проверить результат

ИИ иногда пишет уверенно, но неверно. Прочитайте теорию и особенно **правильные ответы** в тренировке:
ошибка в ответе научит вас неправильному. Сверяйте важные факты с первоисточниками.

## Ваши данные

Всё хранится на вашем компьютере в хранилищах Docker и переживает перезапуск. Резервную копию
сделайте командой (она положит файл `ege-backup.db` в текущую папку):

```sh
docker compose cp backend:/data/ege.db ege-backup.db
```

## Что-то не работает

- **Страница не открывается.** Убедитесь, что Docker Desktop запущен, и выполните `docker compose ps`:
  обе службы должны быть в состоянии «running».
- **В админке пишет «Админка выключена».** Не задан пароль: проверьте файл `.env` и перезапустите
  командой `docker compose up -d`.
- **Порт 3000 занят.** Закройте программу, которая его использует, или измените `3000:3000` на другой
  порт, например `3100:3000`, в файле `docker-compose.yml`.

## Для разработчиков

Стек: FastAPI + SQLite (бэкенд, порт 8008), Next.js (фронтенд, порт 3000). Лицензия MIT, см. `LICENSE`.

Запуск без Docker:

```sh
cd backend
python3 -m venv venv && venv/bin/pip install -r requirements.txt   # один раз
ADMIN_PASSWORD=секрет venv/bin/uvicorn app:app --reload --port 8008

cd frontend
npm install        # один раз
npm run dev
```

Структура:

- `backend/app.py` — всё API. SQLite-файл `backend/ege.db` создаётся пустым при первом старте,
  старые базы при старте мигрируют. Админка: HTTP Basic, пароль из переменной `ADMIN_PASSWORD`
  (имя пользователя не проверяется); если переменная не задана, админ-эндпоинты отвечают 503.
- `backend/seed_demo.py` — демо-проект с 19 темами (пересоздаёт только себя).
- `backend/seed_content.py` — загрузчик учебных проектов из `backend/content/` (по файлу на тему:
  теория по главам, задачи с разбором, тренировка). Сами материалы в репозиторий не входят:
  `backend/content/` в `.gitignore`, реестр проектов — локальный `backend/content/projects.py`:
  `PROJECTS = {ключ: (название проекта, префикс файлов, разрешены ли LaTeX-формулы)}`.
  Загрузчик проверяет контент (`seed_content.py <ключ> --check`) и заполняет проект с этим названием,
  сохраняя его id; прогресс, заметки и словарь этого проекта при перезаливке сбрасываются.
  В Docker: `docker compose up -d --build backend && docker compose exec backend python seed_content.py <ключ>`.
- `backend/test_api.py` — самопроверка: `venv/bin/pip install httpx && venv/bin/python test_api.py`
  (`httpx` нужен только тестам).
- Таблицы: `projects`, `tasks`, `theory_sections` (связь глав — `parent_id`, `read` — прочитана ли),
  `problems` (`kind`: example или practice; `explanation_md` — разбор, `solution_md` — ответ для проверки,
  `solved`, `user_note`), `glossary`, `progress`. Прогресс «теория» вычисляется на бэкенде из прочитанных глав.
- Контент — markdown с формулами KaTeX. Картинки из админки лежат в `backend/static/uploads/`.
- Ответ в тренировке сравнивается на клиенте без учёта регистра и пробелов, запятая и точка равны.
